关于第一次利用hexo和git搭建属于自己的博客

发表于2026-05-07|更新于2026-05-08
|浏览量:

内容

折腾了很久，终于将自己的个人博客成功部署上线。从环境搭建、主题配置到最终部署，经历了大大小小的坑。这里会提到一些我印象比较深刻的部分。

第一阶段

1.安装Node.js
Hexo基于Node.js运行，生成静态页面。
建议访问Node.js官网，下载的时候建议勾选“Automatically install the necessary tools”​ 这个选项（Windows 上会安装必要的编译工具）。

打开open git bash here 在终端里输入 npm -v 验证，
应显示类似 10.7.0

安装Git
（这里因为我之前在linux系统的粗略学习的时候，已经配置好了所有后续再讲解方法。）大致就是用来管理我的博客，并推送到 GitHub，以后的很多重要操作就是在open git bash here终端里实现的，不像windows系统的图形化页面，主要依靠命令行来实现。

在官网下载好后 在bash里 git –version ，
应显示类似 git version 2.45.0

配置npm镜像源

设置淘宝镜像源
[npm config set registry https://registry.npmmirror.com/]
验证是否设置成功
npm config get registry
应该显示 https://registry.npmmirror.com/

现在初始的环境配置基本结束，现在需要在bash里面创建博客项目

第二阶段

创建博客项目 （骨架的搭建)

全局安装hexo命令行工具
依旧是在bash上（右键桌面选择open git bash here）
这会在你的电脑上安装 hexo 命令
npm install -g hexo-cli
安装后验证
hexo -v

初始化博客项目
hexo init myBlog（创建一个文件夹，并初始化hexo，用于存放以后生成的文件）

cd myBog(进入文件夹，以后的操作都是在这里面进行，记住每次打开bash先切换到这个文件夹)

安装项目依赖
npm install
这个命令会安装所有必需的模块，完成后，会多出一个node_modules/ 文件夹

首次本地预览
现在你就可以初步预览自己的博客了~~~
hexo clean && hexo g && hexo s
hexo clean : 清除缓存文件和已经生成的静态文件，每次修改后必须执行！！
hexo g：重新编译生成静态文件到public文件夹。
hexo s： 启动服务器，只能用于本地预览。
（后续git连接GitHub仓库后，会用到另一个经常用的命令 hexo d,d表示delivery，上传到GitHub仓库）

打开浏览器，访问 http://localhost:4000。你应该能看到 Hexo 的默认“Hello World”页面。
但是目前只是本地预览，其他人并不能看见，这个还需要依赖后续上传到GitHub仓库了。
